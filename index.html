Hangul Basics 한글 기초

Good news! Korean uses a phonetic alphabet called Hangul (한글), similar to Japanese hiragana/katakana.

好消息！韩文使用拼音文字，类似日文的假名系统。

Grammar Basics 基本文法

Word Order 语序 / 語順

Korean 한국어
나는 + 사과를 + 먹어요
Subject + Object + Verb
Chinese 中文
我 + 吃 + 苹果
Subject + Verb + Object
Japanese 日本語
私は + りんごを + 食べます
Subject + Object + Verb ✓ Same!

Great news! Korean has the same SOV word order as Japanese!

好消息！韩语的语序和日语一样（主语-宾语-动词）！

Particles 助词 (조사)

은/는 (eun/neun)
Topic marker
🇯🇵 は (wa) - Same function!
🇨🇳 No direct equivalent
저는 학생이에요 (I am a student)
이/가 (i/ga)
Subject marker
🇯🇵 が (ga) - Identical!
🇨🇳 No direct equivalent
누가 왔어요? (Who came?)
을/를 (eul/reul)
Object marker
🇯🇵 を (wo) - Same!
🇨🇳 把 (bǎ) - similar
밥을 먹어요 (eat rice)
의 (ui)
Possessive
🇯🇵 の (no) - Same!
🇨🇳 的 (de)
나의 책 (my book)

Politeness Levels 敬语 / 敬語

Like Japanese, Korean has multiple politeness levels!

和日语一样，韩语也有敬语系统！

Formal Polite (합니다체)
먹습니다 (meok-seum-ni-da)
🇯🇵 Similar to です/ます form
Official settings, news, presentations
Informal Polite (해요체)
먹어요 (meo-geo-yo)
🇯🇵 Most common, like です/ます
Daily conversation, most common
Casual (반말)
먹어 (meo-geo)
🇯🇵 Like plain form だ/である
Close friends, younger people
